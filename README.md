# PDF Reader для Android

Минималистичный PDF-ридер: Kotlin + Jetpack Compose, рендер через встроенный `PdfRenderer` (без сторонних библиотек).

## Скачать
**[Скачать APK (v1.1)](https://github.com/ileshchanka/pdf-reader-android/releases/download/v1.1/pdf-reader-1.1.apk)** · [все релизы](https://github.com/ileshchanka/pdf-reader-android/releases)

Android 7.0+. APK подписан debug-ключом, поэтому при установке Android попросит разрешить установку из неизвестных источников.

## Возможности
- **Полноэкранный режим**: тап по странице прячет статус-бар, навигацию и панели; свайп от края временно показывает системные панели; повторный тап или «Назад» — выход. Используется и область выреза камеры.
- Вертикальная прокрутка страниц, pinch-to-zoom (до 5×) с перерисовкой в высоком разрешении, двойной тап — 1× ↔ 2.5×.
- Нижняя панель: слайдер по страницам и счётчик «12 / 340», тап по счётчику — переход к странице.
- В полноэкранном режиме — исчезающий бейдж с номером страницы.
- Обрезка пустых полей по ширине (включается для каждого файла отдельно).
- Ночной режим (инверсия цветов страниц).
- Запоминает последнюю страницу каждого файла; на главном экране — список недавних файлов (крестик убирает файл из списка).
- Открытие через кнопку или «Открыть с помощью» из файлового менеджера, почты, мессенджеров.
- Экран не гаснет во время чтения.
- Интерфейс на 17 языках (английский, русский, испанский, португальский, французский, немецкий, итальянский, польский, украинский, турецкий, арабский, хинди, индонезийский, японский, корейский, китайский упрощённый и традиционный) — по языку телефона (на Android 13+ язык можно выбрать отдельно для приложения в настройках).

## Сборка
Android Studio (Ladybug или новее): открыть папку → Gradle Sync → Run ▶ (Android 7.0+).

Из командной строки (нужны JDK 17 и Android SDK, путь к SDK — в `local.properties` или `ANDROID_HOME`):
```
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
./gradlew installRelease    # установить на подключённое устройство
```

Release-сборка для простоты подписывается debug-ключом.
