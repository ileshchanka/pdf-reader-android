# PDF Reader для Android

Минималистичный PDF-ридер: Kotlin + Jetpack Compose, рендер через встроенный `PdfRenderer` (без сторонних библиотек).

## Возможности
- **Полноэкранный режим**: тап по странице (или кнопка ⛶ в тулбаре) прячет статус-бар, навигацию и панели; свайп от края временно показывает системные панели; повторный тап или «Назад» — выход. Используется и область выреза камеры.
- Вертикальная прокрутка страниц, pinch-to-zoom (до 5×) с перерисовкой в высоком разрешении, двойной тап — 1× ↔ 2.5×.
- Нижняя панель: слайдер по страницам и счётчик «12 / 340», тап по счётчику — переход к странице.
- В полноэкранном режиме — исчезающий бейдж с номером страницы.
- Ночной режим (инверсия цветов страниц).
- Запоминает последнюю страницу каждого файла; на главном экране — «Продолжить: …».
- Открытие через кнопку или «Открыть с помощью» из файлового менеджера, почты, мессенджеров.
- Экран не гаснет во время чтения.

## Сборка
Android Studio (Ladybug или новее): открыть папку → Gradle Sync → Run ▶ (Android 7.0+).

Из командной строки (нужны JDK 17 и Android SDK, путь к SDK — в `local.properties` или `ANDROID_HOME`):
```
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
./gradlew installRelease    # установить на подключённое устройство
```

Release-сборка для простоты подписывается debug-ключом.
